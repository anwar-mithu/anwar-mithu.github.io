# Anwar Mithu — AI Engineer Portfolio

Static GitHub Pages edition of the WordPress portfolio theme. The front-end design, typography, colors, cards, motion, blog, travel page, empty projects archive and empty certificates archive match the WordPress build.

## Publish at anwar-mithu.github.io

1. Create or open the GitHub repository named **anwar-mithu.github.io**.
2. Upload **the contents of this folder** to the repository root (do not upload the parent folder as one nested folder).
3. Commit to the `main` branch.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then save.
7. Your site URL is `https://anwar-mithu.github.io/`.

## Edit later

- Homepage: `index.html`
- Projects: `projects/index.html`
- Certificates: `certificates/index.html`
- Blog: `blog/`
- Travel: `travel/index.html`
- Main styling: `assets/css/style.css`
- Animations/navigation: `assets/js/main.js`
- Travel illustrations/images: `assets/images/`
